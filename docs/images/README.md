# Images

`workspace.png` is a screenshot of the default `cockpit` layout: Yazi across the
top with a file preview, an agent pane and a shell below, inside Zellij with
full pane frames.

To retake it, open a workspace at a clean checkout, size the window to roughly
1920x1045 so the capture is legible at the width the README uses, and crop to
the terminal window alone.
